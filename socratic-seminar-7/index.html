Other Bitcoin Tech

MC: Shytypes

  • NIP-47: Protocol for connecting Nostr clients to remote Lightning wallets.
  • Enables secure wallet access via end-to-end encrypted Nostr DMs.
  • Roles:
    • Client: requests wallet actions.
    • Wallet Service: API server.
    • User: links wallet.
  • Event Kinds:
    • 13194: Info
    • 23194: Request
    • 23195: Response
    • 23196: Notification
  • Connection: via URI (includes wallet pubkey, relay, secret).
  • Commands: pay_invoice, make_invoice, get_balance, etc.
  • Notifications: payment_received, payment_sent.
  • Security: one-time keys per session, improves privacy.
  • Use Cases: works for custodial/non-custodial wallets on any platform.
