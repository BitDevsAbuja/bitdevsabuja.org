In Bitcoin

MC: Tuedon

Decoding Bitcoin Transactions

Brief

  • Understand the structure of a raw Bitcoin transaction
  • Decode a raw Bitcoin transaction manually and with available tools
  • Identify and explain the purpose of each transaction field
  • Understand transaction inputs, outputs, scripts, witness data, locktime, and version fields
  • Read transaction data directly from a block explorer or node RPC output

Bonus

  • Decode the transaction live and inspect every field together
