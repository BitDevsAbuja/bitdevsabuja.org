### In Bitcoin

---

MC: Tuedon

#### Decoding Bitcoin Transactions

**Brief**

* Understand the structure of a raw Bitcoin transaction
* Decode a raw Bitcoin transaction manually and with available tools
* Identify and explain the purpose of each transaction field
* Understand transaction inputs, outputs, scripts, witness data, locktime, and version fields
* Read transaction data directly from a block explorer or node RPC output

**Bonus**

* Create and broadcast a Bitcoin transaction during the session
* Decode the transaction live and inspect every field together

### Where to Learn

* [Learn Me a Bitcoin - Transactions](https://learnmeabitcoin.com/technical/transaction/)

  * Detailed breakdown of every transaction component
* [Mastering Bitcoin (Open Edition)](https://github.com/bitcoinbook/bitcoinbook)

  * Chapters covering transaction construction, scripts, and serialization
* [Bitcoin Developer Documentation](https://developer.bitcoin.org/reference/transactions.html)

  * Reference guide to transaction fields and formats
* [Mempool.space](https://mempool.space/)

  * Explore and inspect real Bitcoin transactions
* [But how does bitcoin actually work? (3Blue1Brown)](https://www.youtube.com/watch?v=bBC-nXj3Ng4)

  * Visual explanation of cryptographic primitives, hashing, and proof-of-work
